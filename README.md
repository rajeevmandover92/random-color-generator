# Random Color Generator 🎨

A simple project built using HTML, CSS, and JavaScript that generates random RGB colors dynamically.

## Features
- Generate random RGB colors
- Change background color dynamically
- Display generated RGB value
- Simple and beginner-friendly UI

## Technologies Used
- HTML
- CSS
- JavaScript

## How It Works
When the user clicks the "Generate Color" button:
1. JavaScript generates random values for RGB
2. A random color is created using `rgb()`
3. The background color updates dynamically
4. The RGB value is displayed on the screen
